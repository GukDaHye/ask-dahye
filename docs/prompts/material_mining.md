# 자소서 소재 채굴 지시

목적: **업무 자동화 역량**을 보여줄 소재를 사건 단위로 모은다. 감상과 일반론은 뺀다.

대상: 이 저장소의 코드, `docs/`, git 히스토리, 내가 붙여넣는 작업 대화.

## 소재 하나의 형식

```
제목     — 한 줄, 사건으로 (해결책이 아니라 사건)
상황     — 언제 무엇을 하다가
판단     — 내가 무엇을 기준으로 결정했는가 (내 지시 원문이 있으면 인용)
행동     — 실제로 무엇을 바꿨는가 (커밋 해시 · 파일명)
결과     — 숫자가 있으면 등급 표시. 없으면 "숫자 없음"이라고 적는다
검증가능 — 면접관이 확인하려면 어디를 보면 되는가
분류     — [통제] [신뢰성] [범위관리] [측정] [보안] [실패기록]
```

## 규칙

- 근거가 문서 서술뿐이고 실행 기록이 없으면 **"근거 약함"**으로 표시한다.
- 문서 간 숫자가 어긋나면 **어긋난 채로 둘 다 적고 표시한다.** 하나를 골라 정리하지 마라.
- "AI 덕분에 N% 빨라졌다"류는 쓰지 않는다. 대조군이 없다.
- 내가 AI 제안을 **거부한 사건**, 내가 **틀린 사건**도 같은 비중으로 적는다. 그게 통제력의 증거다.
- 이미 `docs/cover_letter_*.md`에 쓴 소재는 "기존 사용됨"으로 표시하고 중복해서 새로 만들지 않는다.
